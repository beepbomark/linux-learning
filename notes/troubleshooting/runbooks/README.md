# Runbooks

Symptom-first checklists. Start here when something is broken.

- [Disk Full](disk-full.md): Writes fail with `No space left on device`, services crash, or logins hang.
- [Service Won't Start](service-wont-start.md): `systemctl start NAME` fails, or the service starts and exits.
- [Can't SSH In](cant-ssh.md): `ssh` hangs, is refused, or rejects your key.
- [High Load or Slow Server](high-load.md): Commands are slow, load average is high, or requests time out.
- [DNS Not Resolving](dns-broken.md): `ping 1.1.1.1` works but `ping example.com` fails, or applications report unknown host.
