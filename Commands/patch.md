# Linux `patch` Command

The `patch` command applies changes from a **diff/patch file** to an existing file or directory.

It is commonly used to:
- Apply changes generated by `diff`
- Update source code
- Apply bug fixes
- Reverse previously applied changes
- Test whether a patch can be applied safely

---

## Key Points

- Patch files are commonly created with `diff -u`
- `patch` reads the instructions inside the patch file
- `-pN` controls how many directory levels are removed from file paths
- `--dry-run` tests a patch without modifying files
- `-R` reverse a patch
- Always review or test a patch before applying it

---

## 1. Basic Workflow

Create a patch:
```bash
diff -u old.txt new.txt > changes.patch
```

Apply the patch:
```bash
patch old.txt < changes.patch
```

---

## 2. Basic Syntax

```bash
patch [OPTION] [FILE] < PATCH_FILE
```

Example:
```bash
patch file.txt < changes.patch
```

Can also use:
```bash
patch < changes.patch
```

If the patch file contains the target filename, `patch` can usually determine which file to modify.
